{% trans "Find answers to common questions about renting and listing tools." %}

{% trans "For Renters" %}

{% trans "How do I rent a tool?" %}

{% blocktrans %}1. Sign up for a free Rentora account
2. Browse available tools by category or search
3. Click on a tool to view details, photos, and reviews
4. Select your rental dates and send the request — nothing is charged yet
5. You land on a confirmation page and get an email; the owner reviews your request
6. Once approved, pay via Stripe from "My Rentals" and the dates are yours{% endblocktrans %}

{% trans "How much does it cost?" %}

{% blocktrans %}Rental costs depend on the daily rate set by the tool owner. At checkout, you'll see:{% endblocktrans %}

  • {% trans "Rental Total:" %} {% trans "rental days × daily rate" %}
  • {% trans "Platform Fee:" %} {% trans "15% of rental total (supports servers and support)" %}
  • {% trans "Damage Protection (optional):" %} {% trans "+$10 for accidental damage coverage" %}

{% trans "The total is charged upfront to your card." %}

{% trans "What is a deposit?" %}

{% blocktrans %}A deposit is a security amount held by Rentora to protect the tool owner against damage. It's NOT charged in addition to rental cost—it's included in your payment. When you return the tool in agreed condition, the deposit is refunded.{% endblocktrans %}

{% blocktrans %}If there's a dispute over tool condition, Rentora staff will review evidence and decide on refund or claim.{% endblocktrans %}

{% trans "How long can I rent a tool?" %}

{% blocktrans %}No minimum or maximum—you and the owner agree on dates. You can rent for 1 day, 1 week, or longer. Select your preferred start and end dates at checkout.{% endblocktrans %}

{% trans "What if I return the tool late?" %}

{% blocktrans %}Each late day is charged as one extra rental day, at the normal daily rate. There is no penalty multiplier.{% endblocktrans %}

{% blocktrans %}Example: at $10/day, returning 2 days late adds $20 to your total.{% endblocktrans %}

{% blocktrans %}To avoid this: hand the tool back on time and ask the owner to press "Mark as Returned" while you are both there. You get a notification and an email — confirm the return from "My Rentals" straight away and the charges stop at that moment.{% endblocktrans %}

{% trans "What if the tool is damaged when I receive it?" %}

{% blocktrans %}Message the owner straight away through the in-app chat and take photos of the tool's condition before you use it. Keeping it in the chat means there is a timestamped record both sides can rely on.{% endblocktrans %}

{% blocktrans %}If you cannot agree, contact support from the Contact page. And when the owner later marks the tool as returned, you can choose Dispute instead of Confirm — that opens a formal case where you attach your reason and photo evidence for staff to review.{% endblocktrans %}

{% trans "Can I cancel my rental?" %}

{% blocktrans %}Yes. Open My Rentals and press Cancel on the booking. What happens depends on the stage:{% endblocktrans %}

  • {% trans "Before you have paid:" %} {% trans "cancel yourself, instantly and free. Nothing has been charged, so there is nothing to refund, and the dates are released for others." %}
  • {% trans "After you have paid:" %} {% trans "the Cancel button is disabled so neither side can void a paid rental alone. Contact support and we will handle the refund." %}
  • {% trans "During an active rental:" %} {% trans "return the tool and complete the return handshake — you are charged only for the days you actually kept it." %}
{% trans "How do I rate a tool or owner?" %}

{% blocktrans %}Once the return is confirmed the booking moves to Completed, and a "Leave Review" button appears on it for both sides. Go to "My Rentals" (or "Booking Requests" if you are the owner) → the completed booking → Leave Review. You can rate on:{% endblocktrans %}

  • {% trans "Tool Quality:" %} {% trans "Condition, functionality, features" %}
  • {% trans "Owner Communication:" %} {% trans "Responsiveness and helpfulness" %}

{% trans "Reviews are public and help other renters make informed decisions." %}

{% trans "For Tool Owners" %}

{% trans "How do I list a tool?" %}

{% blocktrans %}1. Sign up or log in to your Rentora account
2. Go to "Dashboard" → "List Your Tool"
3. Fill in tool name, description, category, and condition
4. Set your daily rental rate and deposit
5. Add your location
6. Upload clear photos of your tool
7. Click "Publish" to make it live{% endblocktrans %}

{% blocktrans %}You do not manage a calendar. A published tool is available every day by default, and Rentora automatically blocks any dates that are already booked so two people can never reserve the same window.{% endblocktrans %}

{% trans "How do I set the daily rate?" %}

{% blocktrans %}You decide the daily rate. Consider:{% endblocktrans %}

  • {% trans "Original cost of tool and depreciation" %}
  • {% trans "Condition and features" %}
  • {% trans "Similar tools' rates on Rentora" %}
  • {% trans "What similar tools nearby are going for" %}

{% blocktrans %}We recommend 5-10% of the tool's original price per day. Example: $500 tool → $25-50/day.{% endblocktrans %}

{% trans "How much do I earn?" %}

{% blocktrans %}Your earning = (rental price × days) - 15% platform fee - Stripe payment processing fee.{% endblocktrans %}

{% blocktrans %}Example: 3-day rental at $25/day{% endblocktrans %}

  • {% trans "Renter pays: $75" %}
  • {% trans "Platform fee (15%): $11.25" %}
  • {% trans "You receive: $63.75" %}

{% trans "You can view detailed earnings in your Dashboard." %}

{% trans "How do I handle the return process?" %}

{% blocktrans %}Do the handover and the handshake together, in person — that is what protects both of you:{% endblocktrans %}

  1. {% trans "Meet the renter and inspect the tool with them present" %}
  2. {% trans "Go to Dashboard → Booking Requests" %}
  3. {% trans "Press \"Mark as Returned\" right there at handover" %}
  4. {% trans "The renter instantly gets a notification and an email" %}
  5. {% trans "They press \"Confirm Return\" on the spot — and the rental is complete" %}

{% blocktrans %}Why on the spot: late fees keep accruing until you mark the tool returned. Doing it at handover means the renter is never charged for time the tool was already back with you, and you are never left waiting on a confirmation.{% endblocktrans %}

{% trans "What if the tool is damaged upon return?" %}

{% blocktrans %}Inspect the tool with the renter still there, before you mark it returned:{% endblocktrans %}

  1. {% trans "Take photos or video of the damage there and then" %}
  2. {% trans "Raise it with the renter in the in-app chat, so there is a timestamped record" %}
  3. {% trans "Contact support from the Contact page with your photos and the booking number" %}
  4. {% trans "Rentora staff review both sides and decide within 5 business days" %}
  5. {% trans "A damage claim can be settled from the deposit held on the booking" %}

{% blocktrans %}If the renter opted for damage protection, insurance covers claims up to the deposit amount.{% endblocktrans %}

{% trans "Can renters cancel bookings?" %}

{% blocktrans %}Yes — but only while no money has changed hands. A renter can cancel their own request before they pay, which simply frees your dates again and notifies you by email.{% endblocktrans %}

{% blocktrans %}Once a rental is paid, neither side can cancel it alone. The renter has often paid before collecting the tool, so leaving that decision to one party would be unfair to the other. Paid cancellations go through Rentora support, which handles the refund.{% endblocktrans %}

{% trans "How do I get paid?" %}

{% blocktrans %}Your earnings from every completed rental are tracked on your Dashboard under Total Earnings, and each payment shows the exact split between your payout and the platform fee.{% endblocktrans %}

{% blocktrans %}Self-service bank payouts are not live yet. Until they are, contact us from the Contact page to arrange your transfer and we will confirm the amount against your completed rentals. We will announce automatic payouts here as soon as they launch.{% endblocktrans %}
